Stellt ein gefuehrtes Redaktionsformular fuer standardisierte Beitraege sowie ein einfaches Bild-Karussell bereit.

== Beschreibung ==

Das Plugin fuegt im WordPress-Beitragseditor ein einfaches Formular fuer Redaktor:innen hinzu:

1. Layouttyp waehlen
2. Einleitung schreiben
3. Haupttext erfassen
4. Abschluss/Hinweis erfassen
5. Beitragsbild oder Galerie pflegen

Verfuegbare Layouts:

1. Titelbild oben
2. Bild links, Text rechts
3. Bilderkarussell

Zusatzfunktion:

* Shortcode `[avf_post_carousel ids="12,34,56"]`
* Erwartet mindestens zwei Bild-Anhangs-IDs aus der Mediathek
* Rendert ein leichtgewichtiges, eigenes Frontend-Karussell

== Verwendung ==

1. Plugin aktivieren.
2. In WordPress einen neuen Beitrag anlegen.
3. Im Bereich "AVF Beitragsformular" das gefuehrte Layout aktivieren.
4. Layout waehlen und Felder ausfuellen.
5. Fuer Hero/Split das normale WordPress-Beitragsbild setzen.
6. Fuer Carousel mehrere Bilder im Formular auswaehlen.
7. Beitrag speichern oder veroeffentlichen.
